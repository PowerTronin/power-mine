# Changelog

## 0.2.0 - 2026-07-30

- Added separate launcher log windows, log focus mode, and basic log appearance controls.
- Added broader Codex automation for profile install/repair/launch, world entry, screenshots, inventory, crafting, interaction checks, and block placement/breaking.
- Added Forge `1.7.10` and Forge `1.12.2` runtime bridge agents alongside the Fabric `1.20.1` agent.
- Improved launcher UI with the Powertronin visual refresh, separate pane scrolling, modal review windows, and custom dropdown controls.
- Added profile stop handling and pause-on-lost-focus safeguards for Codex-driven Minecraft sessions.

## 0.1.0 - 2026-05-22

Initial Power Mine preview release.

- Minecraft profile library with install, repair, launch, and per-profile settings.
- Offline account mode for offline servers.
- Java runtime checks and launcher-managed Java installation.
- Fabric, Quilt, Forge, NeoForge, and Vanilla profile support.
- Modrinth browse, install, dependency handling, update checks, and deletion flows.
- Local mod management with enable, disable, delete, bulk selection, and import.
- Game and launcher logs view.
- Modrinth `.mrpack` import and export.
